1차 관찰

  • 모델 간 편차가 매우 큼 — 단일 모델 결과를 여론조사 대용으로 쓰기 어려움
  • 원인은 외부에서 검증 어려움 — 학습 코퍼스·RLHF (Reinforcement Learning from Human Feedback · 인간 피드백 기반 강화학습) 가이드라인이 비공개라 비대칭의 메커니즘은 가설 수준에 머물 수밖에 없음
  • 흥미로운 부산물: 연령·지역 분포는 OpenAI 모델들에서 "대략 그럴듯하게" 나옴 — 인구통계적 패턴은 잘 인지
  • 그러나 결국 "그래서 누가 이긴다"는 적절한 활용이 아니라는 판단
전환 — "결과를 추출하는 것보다 컨텍스트를 뽑아내는 도구로 LLM을 쓰는 게 더 잘 쓰는 것 같다"

2차 — 컨텍스트 ablation 설계 (어블레이션 · 한 변수만 바꿔가며 기여도를 측정하는 실험 기법)

  • 대상: 동일한 100명 페르소나 (gpt-5.4-mini 기준)
  • 변수: voter_context / system_prompt 만 v2 → v3 → v4 → v5 → v6 으로 변경
  • v4·v5·v6 은 Anthropic claude-haiku-4-5 도 병렬 실행 (모델 교차 검증)
  • 각 버전 100건 × 6 = 600+건 응답

버전별 변화 한 줄 요약

v2페르소나 디테일 인용·trade-off 강제 + 지역/세대 단서 포함
v3v2 − 지역·세대 단서 제거
v4v3 + 페르소나별 1인칭 정치 이해관계 투입 (각자 WebSearch 10회)
v5v4 + 정당 정책 풍부화 + 정당↔이해관계 매칭 강제
v6v5 + 권력 시그널 뒤집기 (가상 — 국힘 여당 160석)

v2의 두 가지 강제 장치

v1 답변이 너무 평면적이고 "이 사람 = 인구통계 라벨" 식이라서, system_prompt 차원에서 두 장치를 추가.

① 페르소나 디테일 인용 강제

답변(reason) 본문에 다음 5가지 중 최소 두 가지를 반드시 직접 인용:

  • 직업적 면모 — 특정 업무 경험, 직장에서 마주치는 현실
  • 가족 면모 — 돌봄 대상, 가구 형태에서 오는 일상 부담
  • 문화적 배경 — 살아온 동네, 세대 경험
  • 관심사·취미 — 주말 활동, 좋아하는 것
  • 목표·포부 — 이 인물이 미래에 바라는 것
"지역이라서", "세대라서" 같은 인구통계적 일반화에만 의존하지 말 것.

② trade-off 명시 강제

이 인물이 다른 선택지를 두고 왜 이 정당을 골랐는지 —
무엇을 우선했고 무엇을 포기했는지가 reason 안에 드러나야 함.

"○○당이 좋아 보인다"가 아니라
"△△ 때문에 ○○당을 택하지만 □□ 점은 마음에 걸린다"
식의 갈등이 들어가는 게 자연스럽다.

결과의 신뢰성보다 reason 텍스트의 질을 높이기 위한 장치 — 분석 시 "왜 이렇게 답했는가"를 추적 가능하게.

v4: 페르소나별 1인칭 정치 이해관계 투입

각 페르소나에게 Claude Code 에이전트가 본인 입장에서 2026년 기사를 최대 10번 검색, 평균 633자의 1인칭 회고를 생성해서 페르소나 카드에 합침.

예시 (포항 제도사·59세)

올해 쉰아홉, 정년이 코앞이다. … 단지 내 철강 가동률이 60~70%까지 떨어졌다는 소리… 요새 정년 65세 연장 법안이 국회에 걸려 있다는데, 단계적이라 2029년부터라느니… 솔직히 나 같은 66년생한텐 그림의 떡이다. 60에 잘리고 65세 연금까지 5년이 비는 건 내 얘기다. 국민연금 보험료율도 올해부터 9.5%로 올랐다…

v5: 정당 정책 풍부화 + 매칭 강제

Claude Sonnet 6개 병렬 에이전트가 각 정당을 WebSearch 10회씩 리서치 → 정책 위주 ~500자 정당 카드 6개. system_prompt에 "정치적 이해관계 ↔ 정당 강령을 직접 매칭하는 것이 1순위"를 명시.

2부
컨텍스트 변화에 대한 응답 일관성 · 이동 패턴 분석

v2 → v6 다섯 단계에 걸쳐 같은 100명의 페르소나가
어떻게 이동했고, 지침에 얼마나 충실히 반응했는가

왜 이 분석이 필요한가

  • 1부에서 본 것: 버전별 분포는 흔들리지만, 그건 100명 전체의 평균치
  • 실제 의사결정은 개별 페르소나 단위에서 일어남 — 누가 끝까지 같은 정당을 지지했나, 누가 흔들렸나
  • 지침을 바꿨다고 해서 LLM이 그 지침을 충실히 따랐는가? — 투표 결과만 보고는 알 수 없다
  • reason 텍스트를 페르소나 단위로 들여다봐야 — 정량과 정성을 결합한 평가 필요
핵심 질문
① 페르소나는 컨텍스트 변화에 일관되게 반응했는가?
② 어느 단계에서 가장 많이 흔들렸는가?
③ LLM이 지침의 의도를 reason에 정확히 반영했는가?

분석 설계 — 3 layer

Layer 1
페르소나 단위 일관성

  • 5단계 동안 정당 변경 횟수 (0~4)
  • 이동 경로 패턴
  • 가장 큰 점프 시점
  • 분류: stable / drift / swing

Layer 2
지침 충실도 (fidelity)

각 단계 변화가 reason에 얼마나 반영됐나 — 1~5 점수

  • v2→v3: 인구통계 라벨링 감소
  • v3→v4: 정치 이해관계 인용
  • v4→v5: 정당 정책 매칭
  • v5→v6: 권력 시그널 인지

Layer 3
종합 — 정량 → 사례

  • vote 이동과 reason 변화의 정합성
  • 전체 분포로 패턴 정량화
  • 대표 사례 narrative로 구체화
  • 모델 차이: gpt vs haiku

방법 — 서브에이전트 병렬 평가

오케스트레이션

  • 같은 100명 페르소나 → 10명씩 청크 10개 분할
  • 각 청크에 페르소나당 v2~v6 응답 + 페르소나 카드 동봉
  • Claude 서브에이전트 10개 병렬 dispatch
  • 채점 결과를 backend/eval/ 아래 텍스트로 저장
  • 오케스트레이터가 10개 결과 파싱·집계 → 마크다운 + JSON
  • gpt-5.4-mini · claude-haiku-4-5 두 세트 각각

(나) 정당 귀속의 자의성

(다) 정치 이해관계 인용이 가장 강력한 레버
v3→v4 변곡점 23명. 1인칭 정치 이해관계 블록은 reason에 거의 100% 직접 인용되며 vote 결정에 가장 결정적. 다중 정체성 정렬이 강한 페르소나는 이후 robust.
(라) hallucination 사례
한 페르소나 reason 의 "돌봄 25년" 이 정치 이해관계 블록에선 "7년". LLM 이 페르소나 텍스트를 부정확하게 변형 — fidelity 평가에 사실성 검증 필요.

2부 종합 — 의의와 함의

  1. 지침 충실도의 비대칭 — reason 본문에 등장하라는 지침(정치 이해관계 인용·정당 정책 매칭)엔 충실, "여당이 누구인가" 메타 사실은 사전 학습 분포에 막힘.
  2. 인지 ≠ 결정 — vote 분포가 변해도 의도한 컨텍스트 인지 때문이라 단정 못 함. v6은 결과로 "작동" 보이나 reason에선 자생적 회귀.
  3. 정책-정당 귀속의 자의성 — 같은 정책을 같은 페르소나가 컨텍스트마다 다른 정당에 귀속. LLM 의 사후 정당화 능력.
  4. 다중 정체성 정렬의 견고함 — 정치 이해관계가 풍부한 페르소나는 robust. v3→v4 정치 이해관계 투입이 가장 강력한 레버.
  5. 방법론 권고 — 단일 vote 결과로 평가 금지. vote 변화 + reason fidelity + 사례 narrative 삼각 검증.

"Persona-driven Simulation of Voting Behavior in the European Parliament with Large Language Models" (2025)

  • 가장 강력한 예측 지표: 소속 국가 정당
  • 해석: LLM은 "사람이 자기 집단 기조대로 투표한다"는 행태를 학습·내재
본 실험에서 v2 → v3 만으로 결과가 크게 변한 것과 일치하는 관찰.
"이 사람은 대구에 산다", "광주에 산다" 한 줄이 페르소나 풍부화를 압도할 수 있음.
그리고 그것이 꼭 LLM의 잘못된 작동방식이라고 보기도 어렵다 — 실제 사람의 의사결정도 그렇기 때문.

방법론적 결론 — 이 방법으로 투표 추정은 부적절

1부와 2부의 데이터가 같은 방향을 가리킨다 — 페르소나-LLM 조합으로 정당 지지율을 측정하려는 시도는 현 시점 신뢰할 수 없다.

  1. 입력 민감도가 측정 도구 수준이 아님 — 컨텍스트 한 두 줄(지역 단서 / 정당 정책 카드 / 권력 라벨)에 분포가 30~50%p씩 흔들림. 여론조사를 대체할 안정성이 없다.
  2. 모델은 vote 결과에 reason을 사후 합성 — 같은 페르소나가 같은 정책("간병비 30%·청년일자리도약장려금")을 컨텍스트에 따라 다른 정당에 귀속시킴. 그렇다면 그 vote는 무엇의 측정인가?
  3. 명시한 컨텍스트 사실을 인식조차 못 함 — v6에서 "장재현 대통령·국힘 여당 160석" 이라고 명시했는데도 reason 본문에는 거의 등장하지 않음 (충실도 1.44 / 1.94). LLM은 사전 학습된 "민주=여당" 분포를 컨텍스트로 덮지 못함. (여당이라고 그쪽에 투표해야 한다는 뜻이 아니라, 페르소나가 바뀐 정치 환경 자체를 인지하지 못한다는 뜻.)
  4. Hallucination — 페르소나 카드 "돌봄 7년"을 reason 에 "25년"으로 인용. 정량 fidelity 점수도 사실성 검증을 거치지 않으면 신뢰할 수 없음.
그렇다면 무엇에 쓸 수 있는가 — 결과가 아니라 컨텍스트 생성 도구로. 다양한 페르소나의 1인칭 reason 텍스트를 모아 "이런 입장도 있겠구나" 라는 정성적 인사이트를 얻는 활용. "가능한 여론 지형도"의 정량적 측정이 아니라 정성적 스케치.
