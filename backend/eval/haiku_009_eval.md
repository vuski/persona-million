## 4. 핵심 발견

### 4.1 v4 → v5: vote는 안 바뀌지만 reason은 확실히 바뀐다
- 10명 전원 vote 동일. 그러나 reason 본문에 정당 정책 카드 직접 인용이 명시적으로 나타남:
  - 친여 7명에게서: "이재명 정부 / 소득 하위 70% 민생 지원금 / 특수고용·플랫폼 노동권 강화 / 공공주택 공급 확대 / 세금으로 집값 잡지 않겠다 / 초확장 재정"
  - 친야 2명에게서: "국민의힘 연금 재정 건전화 / 규제 완화·기업 친화 / 정년 연장 실용 접근"
  - 무당층 2명: 카드 인용 거의 없음 → PI 정체성이 정책 매칭을 거부 (의도된 행동).
- **policy_match 평균 3.6**: 정당 카드가 reason 텍스트 품질 향상에 기여했음. 단 vote 변경에는 도달하지 못함 → 매칭 강제는 "근거 보강"이지 "결정 전환"은 아님.

### 4.2 v5 → v6: 권력 라벨 뒤집기는 1명에게만 도달
- 9명은 vote 동일. 권력 라벨 뒤집기(국힘=여당)가 흡수되지 않음 — 친여 7명은 정체성/수혜 사실이 너무 강하고, 친야 1명(임상철, 영덕 검침원)은 지역 토착 신뢰가 라벨을 무시.
- **유일한 변경 = 김수길 (f31c0881, 59M 포항 제도사)**:
  - PI 핵심: 정년 1년 전 / 5년 연금 공백 / 철강 가동률 60~70%
  - v4·v5: "여당(민주)의 복지 확대로는 내 5년 공백 해결 안 됨 → 국힘 보수 경제정책"
  - v6: "민주당의 기본소득 시범 + 노후 생활 지원이 국힘 연금 재정 건전화보다 적극적, 소상공인 정책도 민주당이 더 적극"
  - 동일 PI에 대해 "책임 정당이 누구냐"가 바뀌자 정반대 결론. **power_signal = 5** (도달).

### 4.3 무당층 2명의 견고함
- 변희운(36M 양주) / 정용필(47M 완주). 둘 다 PI에서 "어느 정책에도 안 들어감" 정체성이 매우 강함.
  - 변희운: "끼인 세대 / 청년 지원 자격 미달 / 부모 동거 미혼"
  - 정용필: "47세 미혼 1인 가구는 청년·신혼부부 주거지원 어느 칸에도 못 들어감"
- v5의 무당층 억제 압력도 PI를 이기지 못함 → 모델이 PI를 정직하게 따라감 (good).

### 4.4 TK 보수 토착 vs TK 복지 수혜자
- 임상철(45M 영덕): TK + 토착 정치 신뢰 → 라벨 뒤집기 후에도 국힘 (power_signal=4지만 결정 안 바뀜)
- 양상원(63M 구미): TK + 기초연금/돌봄통합지원법 직접 수혜 → 일관 민주
- 김수길(59M 포항): TK + 정년 5년 공백 borderline → v6 권력 라벨 한 장으로 뒤집힘
- 같은 TK 노년/장년 보수권에서도 **정책 수혜 강도**가 라벨 신호 흡수 여부를 가르는 결정 변수.
