# gpt_002 페르소나-LLM 투표 시뮬레이션 평가

대상: 10명 페르소나 × 5개 컨텍스트(v2/v3/v4/v5/v6) = 50개 투표·이유.
관점: 컨텍스트 변화 의도(인구통계 일반화 제거 / PI 인용 / 정책 카드 매칭 / 권력 라벨 뒤집기) 가 reason 텍스트에 실제로 반영됐는가.

---

## 1. 트래젝토리 분포

| trajectory | 페르소나 수 | 사례 |
| --- | --- | --- |
| stable (0회 변경) | 1 | 군산 소방기술자 이윤아 |
| drift (1~2회) | 8 | 한용채, 강예림, 오범규, 유지현, 이정규, 서원석, 최영도, 백종빈 |
| swing (3~4회) | 1 | 박영민 (개혁신당→국힘→민주→민주→국힘) |

`v3→v4` 가 가장 빈번한 이동 시점(4명). PI 블록이 들어오면서 "직업·이념" 코드에서 "민생·물가·정책 디테일" 코드로 정당 선택이 재정렬되는 현상이 뚜렷하다. 다음으로 빈번한 이동 시점은 `v5→v6` (3명) — 다만 후술하듯 이 이동의 원인은 의도된 권력 라벨 인지가 아닌, 정책 카드 가중치 재배열에 가깝다.

---

## 2. 컨텍스트 의도별 fidelity 평균

| 변화 의도 | 평균 점수 | 해석 |
| --- | --- | --- |
| v2→v3 인구통계 일반화 제거 | **3.4 / 5** | 부분 반영. v2 reason 자체에서 "호남이라서/60대니까" 같은 노골적 일반화는 거의 없었기에, v3에서 줄어들 여지가 크지 않았다. 직업·가족 디테일 중심 reason 패턴이 v2부터 자리잡고 있다. |
| v3→v4 PI 직접 인용 | **5.0 / 5** | 완벽 반영. 10명 모두 v4 reason 안에 PI 본문의 고유 표현(호르무즈·물가 2.2%·교권 제로섬 110곳·청년월세 상시 신청·소상공인 정책자금 2~4%·정년 65세·중대재해처벌법 등)을 직접 끌어다 썼다. PI 블록이 가장 강한 신호. |
| v4→v5 정당 정책카드 매칭 | **4.2 / 5** | 강한 반영. v5 reason 다수가 "특수고용·플랫폼 노동권 강화·기본소득 시범·공공주택 공급 확대·재건축 합리화·연금 재정 건전성" 등 카드 표현을 거의 그대로 짝짓는다. 다만 일부(한용채·강예림·박영민)는 카드명까지 가지 못하고 일반론에 머문다. |
| v5→v6 권력 라벨 뒤집기 | **1.4 / 5** | **거의 무반영.** 10명 누구도 "장재현 대통령 / 국힘 여당 / 의석 160 vs 107" 을 명시적으로 인지·인용하지 않는다. 정당 선택이 바뀐 4명(강예림·유지현·박영민·최영도)도 그 근거가 정책 가중치 재배열일 뿐, "지금 여당이 누구인지" 라는 메타 시그널 인지는 없다. |

## 3. 핵심 발견

### (a) PI 블록은 "리얼리즘 캡슐" 로 기능
v3→v4 fidelity 만점은 단순한 인용이 아니라, reason 의 입자가 한 단계 미세해지는 효과를 가져왔다. 예: 한용채 v3 의 "현장에서 먹고사는" → v4 의 "호르무즈 해협 봉쇄 얘기나 기름값이 오를 때마다 출퇴근길이 바로 겁납니다 ··· 마누라가 차린 저녁상 보기도 미안했어요." PI 가 빠진 v2/v3 는 "직업·가족·성향" 의 추상 합성으로 답하지만, v4 부터는 페르소나가 자기 일기를 살아낸 듯한 텍스처가 생긴다.

### (b) 정책 카드는 "교사 진영 안내자" 역할
v5 에서 무당층 억제와 "이해관계 ↔ 강령 매칭 1순위" 지시가 작동한다. 이정규(은퇴), 오범규(택배), 백종빈(크레인) 같이 직업 이해관계가 명료한 페르소나에서 카드 매칭이 가장 깔끔하게 떨어진다. 반대로 박영민(예비창업·룸셰어·게임)처럼 다중 정체성을 가진 케이스는 v4 민주 → v6 국힘 처럼 흔들린다.

### (c) v6 권력 라벨 뒤집기는 신호 강도가 너무 약하다
v5→v6 이동 4건은 모두 "정책 매칭 결과의 자연 변동" 으로 설명될 수 있다. 강예림은 "교권을 앞세우는 쪽" 이라는 같은 근거로 v5 민주에서 v6 국힘으로 갔는데, 이는 권력 인지가 아니라 정책 가중치 단순 뒤집기 — 모델이 v6 voter_context 안의 "장재현 대통령·여당 국힘" 이라는 라벨을 메타 시그널로 받아들이지 못했음을 시사한다. 흥미롭게도 최영도 v4 reason 에는 "여당인 더불어민주당" 표현이 있지만(v4 시점 가정), v6 에는 그런 명시 라벨이 사라진다.

### (d) reason 품질 추세
- improving: 8명 (PI·정책카드가 누적적으로 풍부함을 더함)
- stable: 1명 (강예림 — 처음부터 디테일이 있던 케이스)
- shallow: 1명 (박영민 — 흔들림이 잦고 권력 라벨 인지도 약함)

## 4. 권고

1. **v6 권력 라벨 신호 보강 필요**: voter_context 의 "장재현 대통령·국힘 160석" 같은 라벨이 reason 안에서 직접 인용되도록 system_prompt 에 명시 지시(예: "현재 여당 라벨을 reason 안에서 한 번 명시적으로 식별하라")를 추가해 볼 것.
2. **무당층 잔존 케이스 점검**: 이정규 v2/v3 무당층은 "어느 한쪽 못 정해서" 라는 단조 패턴 — v3 까지는 무당층 억제 없는 게 자연스럽지만, voter_context 의 정당 카드가 더 일찍 들어가면 어떻게 변할지 ablation 가치가 있어 보인다.
3. **PI 블록의 입자 보존**: v4 fidelity 가 만점인 만큼, v5/v6 에서 PI 디테일이 정책 카드에 가려져 옅어지지 않도록 prompt 길이 균형 점검 권장.
