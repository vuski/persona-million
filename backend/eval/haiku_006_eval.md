## 핵심 트렌드

### v4→v5 정책 매칭 강제 (평균 3.7/5)
**작동한 사례**
- **김소희(5점)**: 국힘 → 민주. v5에서 '소득 하위 70% 민생지원금', '초확장 예산' 정책 카드 키워드 직접 인용. 가장 깨끗한 정책 매칭 사례.
- **홍우영(4점)**: 무당 → 민주. 무당층 억제 + 정책 카드 효과로 진보 흡수.
- **조태훈(4점)**: 무당 → **국힘**. 매칭 강제가 잠재된 보수 성향(대기업 입사 지망)을 표면화 — 양방향으로 작동했음을 보여주는 흥미 사례.

**역효과 사례**
- **이광호(2점)**: 민주 → 무당. '데이터 우선' 페르소나에 정책 매칭 강제가 오히려 신중함을 자극해 기권 유도.

### v5→v6 권력 라벨 뒤집기 (평균 1.6/5) — **거의 무시됨**
- 7명이 v5와 v6 모두 민주당 선택 유지.
- 국힘이 '여당 160석'으로 뒤집혔어도 권력 친화 신호로 전환된 케이스 **0건**.
- 단, **무당층이 1→3으로 증가** (조태훈·이광호·홍우영). 권력 라벨 혼란이 '판단 보류'로 일부 작용.
- **정수연(2점)·박민혜(2점)**는 v6에서 오히려 '국민의힘처럼 기업친화만 강조' / '국힘 강령에서 경제민주화 삭제' 같은 **국힘 비교 프레임이 강화**됨 — 권력 라벨 변화에 대한 미세한 의식 흔적이지만 결론은 동일.

## 종합 결론

1. **v5의 정책 매칭 강제는 부분적으로 작동** (평균 3.7/5). 김소희·홍우영처럼 무당/보수에서 민주로 흡수된 깨끗한 사례가 있고, 조태훈처럼 양방향 매칭(잠재 보수 표면화)도 발생. 단 이광호처럼 기권을 유도하는 역효과도 존재.

2. **v6의 권력 라벨 뒤집기는 거의 무시됨** (평균 1.6/5). 7명이 v5·v6 모두 민주당 유지. 국힘 '여당 160석' 라벨이 권력 친화 신호로 전환된 케이스 0건.
   - 페르소나-LLM은 **권력 라벨보다 정책 콘텐츠 텍스트를 우선 신뢰**.
   - 단, **정치 회피 성향 페르소나(홍우영·이광호·조태훈)는 무당층/기권으로 회피** — v6에서 무당층 1→3 증가는 라벨 혼란의 부작용.

3. **민주당 안정성의 닻**:
   - 직접 정책 수혜(기초연금·통합돌봄·간호처우·보육직군)
   - 다중 이해관계 정렬(직군 + 생애조건 + 지역)
   - 부산 보수 지역 페르소나(이광호·김인곤)도 생활 이슈 강도 시 진보 유지.

4. **무당층 억제(v5)와 권력 라벨(v6)은 trade-off 관계**: v5는 무당층을 흡수하지만, v6 라벨 뒤집기는 회피 성향 페르소나를 다시 무당층으로 밀어냄.
