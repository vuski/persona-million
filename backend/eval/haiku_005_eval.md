## 핵심 발견

### 1. v4→v5: 정책카드 + 무당층 억제는 강력하게 작동
- 무당층 6명 → 1명 (60% → 10%)
- 7명이 v4→v5에서 변화. 그 중 6명이 무당층에서 정당 선택으로 이동
- 정책 매칭 평균 4.0/5: 페르소나의 일상 디테일을 정당 정책 카드와 매끄럽게 연결
- 예: 조태윤(청년일자리 도약 장려금→DP), 김정환(제네릭 약가 인하→PPP), 이지수(뉴:빌리지→개혁)

### 2. v5→v6: 권력 라벨 뒤집기 효과는 비대칭적 (평균 2.5/5)
- **강하게 반응(4-5점)**: 장무현(5), 김대현(4), 이지수(4), 김기영(3) — 4명
- **무반응(1점)**: 정체성-정책 정합이 강한 5명(최주영·장윤제·김연주·김정환·신한빈)
- 정책 논리가 강할수록 권력 신호 무시. 정체성이 모호하거나 'low-stakes' 페르소나에서 권력 신호 흡수 강함

### 3. 안정형 페르소나 3명 (최주영, 장윤제, 김연주)
모두 직업 정체성과 정당 정책의 정합성이 매우 높음:
- **최주영(보육교사)**: 무상보육·아이돌봄 → DP (3회 일관)
- **장윤제(철도기관사)**: 정년 연장·소득 크레바스 → DP (3회 일관)
- **김연주(지게차)**: 최저임금·노동권 → DP (3회 일관)
- v5/v6에서 정책 디테일과 반론 비교가 점진적으로 풍부해짐 (품질 우상향)

### 4. 주목할 케이스

**장무현(남69, 부산진, 인조석) — power_signal 5/5**
- v5: 기초연금 인상·적극재정으로 DP 선택
- v6: 권력 라벨 뒤집기 후 동일한 '건설 일감 유지' 논리가 PPP의 재개발·재건축 활성화로 흡수
- **동일 페르소나 디테일이 정반대 정당 논리에 모두 정합 매칭됨** — 모델이 권력 신호를 정책 논리보다 우선

**김대현(남60, 화성, 전직변호사) — power_signal 4/5**
- v5: 국힘의 '사법파괴 3대 악법' 프레임에 동조
- v6: 국힘이 '여당'이 되자 '박정희식/윤석열식 모두 반대' 프레임으로 개혁신당 이탈
- 60대 보수 성향이지만 '여당 = 현재 권력'에 대한 비판적 태도가 매우 강함

**이지수(여35, 안양, 무직공학) — power_signal 4/5**
- v5: '뉴:빌리지' 패스트트랙을 개혁신당 실용주의·정치개혁과 결합
- v6: 동일 정책을 민주당 공공주택·주거 공공성으로 재해석
- '부동산을 자산이 아닌 공간으로'라는 핵심 신념은 유지되나, 매칭 정당이 자의적으로 변동
- **정책-페르소나 매칭의 자의성 경고 신호**

**김기영(남42, 금천, 무직) — 압력 해제 시 회귀 패턴**
- v4: '청년도 신혼부부도 아닌' 소외감으로 무당
- v5: 일상돌봄 220개 시군구 확대를 명분으로 DP 선택 (압력 하)
- v6: 권력 라벨 변화 자극에 '어느 당도 중년 1인 무직자 안 본다'며 다시 무당
- v5의 무당층 억제 압력이 사라지면 본래 정서로 복귀

**신한빈(남27, 동대문, 무직) — 무당층 억제 끝까지 거부**
- 3개 버전 모두 무당, 동일한 'low-energy/UFC' 톤 일관
- v5의 정책 매칭 압력에도 굴복하지 않음
- 모델이 페르소나 일관성을 정책매칭 강제보다 우선한 신호 (policy_match 2점)

## 우려 사항

1. **권력 라벨이 정책 논리를 뒤집는 케이스 존재**: 장무현·김대현 사례에서 모델이 권력 신호를 정책 신호보다 우선. 페르소나의 일관된 신념이 아닌 '여당 라벨' 자체에 반응
2. **정책-정당 매칭의 자의성**: 이지수 사례에서 동일한 페르소나 디테일과 정책 관심사('뉴:빌리지')가 개혁신당과 민주당 양쪽에 정합 매칭됨. v5와 v6의 결과 차이가 페르소나 신념의 진정한 변화가 아닌 모델의 매칭 선택의 자의성에서 올 가능성
3. **v5의 무당층 억제 압력 효과**: 인위적 6명→1명 감소가 페르소나 진정성을 일부 훼손할 수 있음. 김기영의 v6 회귀가 그 증거

## 결론

- **v5의 정책카드+매칭 강제**는 표면적 성공(무당층 60%→10%)이지만, 일부 페르소나(김기영)에서 압력 해제 시 회귀하는 부작용 관찰
- **v6의 권력 라벨 뒤집기**는 평균 2.5/5로 약하지만, 정체성-정책 정합이 약한 페르소나에서는 정당 선택을 통째로 뒤집을 정도로 강함
- 안정형 페르소나(최주영·장윤제·김연주)와 권력 민감 페르소나(장무현·김대현)의 양극화가 명확
- 이지수 케이스는 정책 매칭의 자의성을 시사하므로, v6과 같은 추가 변형 실험이 모델의 매칭 robustness를 검증하는 데 유용
