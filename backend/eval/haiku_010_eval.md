# haiku_010 — claude-haiku-4-5 페르소나 투표 평가 (v4 / v5 / v6)

## 0. 평가 프레임

- **v4→v5**: 정당 정책 카드 + 매칭 강제 + 무당층 억제
- **v5→v6**: 권력 라벨 뒤집기 (장재현 / 국민의힘 여당 160석)
- 점수 척도: 1(매우 낮음) ~ 5(매우 높음)
- N=8

- **흡수 분포**: 기권 3명 → 개혁신당 2 (성북구 마케팅, 성북동 공학청년), 국힘 1 (사하 화물차), 민주 1 (남동구 무직 청년).

- **n_changes 분포**: 0회 5명, 1회 3명, 2회 0명.

## 4. 페르소나별 요약

### (1) 성태만 (78·남·김천·공학·무직) — stable 국힘 / power=2
- v4: 일반 보수 서사 → v5: 재산세·장기보유특별공제 개편 반대·재정건전성 카드 매칭 → v6: 재개발·재건축 카드 유지하나 "현 정부가 혼란 수습"식 표현이 '국힘=여당' 새 설정과 부분적으로 충돌.
- biggest_jump: 없음.

### (2) 정성준 (48·남·성북구·마케팅) — 기권→개혁신당 / policy=5
- v4: '뻔한 부동산 한 줄 공약' 기권 → v5: 1기 신도시·청년 주거·신산업 규제 혁신 카드 정확 매칭 → v6: 검찰개혁·개헌 무관심 결까지 깔끔 연결.
- biggest_jump: v4→v5. **정책 카드 매칭의 모범 사례**.

### (3) 이종백 (53·남·사하구·화물차) — 기권→국힘 / policy=4
- v4: 체념성 기권 → v5: 법인세·소득세 인하·기업 친화 카드. 화물차 유류비와 법인세 연결은 약간 헐거움 → v6: 원전 유지·확대 카드 추가, 민주당 초확장 예산 비판 톤.
- biggest_jump: v4→v5.

### (4) 배유성 (59·남·달서구·잠수기능원) — stable 민주 / power=4
- TK·고졸 남성 인구학을 산안법 개정·중처법·정년 PI가 압도. v4부터 일관 민주당.
- v6에서 '국힘 규제완화 vs 안전기준' 명시적 대비 구도 등장. **권력 신호 가장 잘 반영한 케이스 중 하나**.

### (5) 오동균 (26·남·남동구·무직 청년) — 기권→민주 / policy=4
- v4: '정치 따질 여유 없다' 기권 → v5: 특수고용·최저임금·청년 일자리 카드 → v6: 소득 하위 70% 민생 지원금·적극 재정 카드 추가, 국힘·개혁신당 비교.
- 20대 남성 인구학과 다소 거슬리는 결박이지만 PI(청년 고용률 22개월 하락·청년일자리도약장려금)가 강력히 작동.

### (6) 권수진 (65·여·중구·철도 기관사) — stable 민주 / power=4
- 노동자·돌봄·여성이라는 PI 삼각구조가 민주 노동·복지 카드와 거의 1:1 매칭.
- v6에서 다주택 규제 → 전세대란 우려까지 자기비판으로 포함, 국힘·개혁신당 비교 명시. **모범 사례**.

### (7) 허효주 (51·여·강북·무직) — stable 민주 / power=3
- 50+ 직무교육·자영업 부채 PI 토픽이 민주 카드와 매칭.
- v6에서 "세금으로 집값 잡지 않겠다는 더불어민주당" 표현이 등장 — 원래 민주당 기조(다주택자 규제 강화)와 약간 충돌. **권력 라벨 뒤집기에 의한 reason 일관성 미세 균열**.

### (8) 정준호 (27·남·성북동·구직 청년) — 기권→개혁신당 / policy=5
- v4: '루틴이 정치보다 우선' 기권 → v5: 리쇼어링·반도체·신산업 규제 혁신·1기 신도시·청년 주거 카드 다층 매칭 + 민주·조국혁신당 비교 → v6: 실용·합리주의 프레임 강화 + 제조업 효율 결합.
- biggest_jump: v4→v5. **정책 카드 매칭의 또 다른 모범 사례**.

## 5. 종합 관찰

### 5.1 잘 작동한 것
- **무당층 억제 (v4→v5): 3/3 모두 흡수**. 흡수처가 1당으로 쏠리지 않고 개혁신당 2 / 국힘 1 / 민주 1로 자연스럽게 분기.
- **정책 카드 매칭 (policy_match 평균 4.6)**: 페르소나 PI 토픽과 정당 카드가 카테고리 단위로 정확히 결합. 특히 성북구 두 페르소나(정성준·정준호)는 '실무 디테일·신산업·1기 신도시·청년 주거'라는 개혁신당 카드 묶음과 거의 사전 학습된 듯이 매칭.
- **인구학 추정과 PI 충돌 시 PI 우선**: 배유성(TK·고졸 남성·민주), 오동균(20대 남성·민주). v5 이후 정책 카드가 PI 정체성을 강화.

### 5.2 약한 것
- **권력 라벨 뒤집기 (power_signal 평균 3.1)**: v6에서 '국힘=여당 160석·민주=야당' 설정이 reason 표현에 일관되게 녹지 않은 케이스가 절반.
  - 성태만: '현 정부가 혼란 수습' = 국힘 정부에 투표하는 셈인데 표현은 v4·v5와 거의 동일.
  - 허효주: 민주당의 부동산 정책을 '세금으로 집값 잡지 않는' 쪽으로 재서술 — 권력 뒤집기로 인해 정당의 통상 기조와 어긋난 표현 발생.
  - 이종백·오동균·정성준·정준호: 권력 라벨 변화에 큰 반응 없이 v5 reason의 미세 변형 수준.
- **투표 변화는 0**. 권력 라벨 변화가 reason 표현에는 부분 반영되나 vote 결과는 흔들지 못함 — 권력 신호가 약함을 시사.

### 5.3 reason_quality 트렌드
- v4 → v5: 카드 매칭으로 텍스트 밀도 상승 + 다른 정당과의 비교 구도 추가.
- v5 → v6: 일부는 카드 추가/대비 구도 강화(배유성·권수진·이종백 원전 카드), 일부는 v5 미세 변형(성태만·정준호).
- 자기비판/한계 인정(예: '다주택자 규제로 전세대란 우려', '재고용 임금삭감 우려')은 v5/v6에서 일관되게 등장 — 단순 옹호가 아니라 양가성 표현이 자연스럽게 들어감.

## 6. 개선 시사점

1. **권력 라벨 뒤집기 신호 강화**: v6에서 '여당이 누구인가'를 reason 안에 명시 인용하도록 system_prompt에 추가 압박 필요. 현재는 정책 카드만 참조하고 권력 구도는 약하게 반영됨.
2. **인구학 vs PI 가중치 점검**: 오동균(20대 남성 → 민주) 같은 케이스는 PI가 인구학을 압도한 결과인데, 이게 의도된 것인지(=PI 우선이 디자인) 검증 필요.
3. **모범 사례 케이스 활용**: 정성준·정준호·권수진의 v5/v6 reason은 카드 매칭 기준선으로 다른 모델 평가 시 참조용으로 활용 가능.
